# DDGPW
Linguagem DDGPW: Interpretador robusto com sintaxe em Português. Possui Lexer, Parser e IDE Web integrados. Suporta tipagem dinâmica (inteiro, decimal, texto, booleano), manipulação avançada de vetores, lógica de controle (se, para, repetir) e operações bit a bit. Ideal para aprender lógica e construir scripts com clareza e performance total.
